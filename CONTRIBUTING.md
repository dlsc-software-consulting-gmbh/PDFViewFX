# Contributing to PDFViewFX

Thank you for your interest in contributing to PDFViewFX.

## Prerequisites

- JDK 21
- Git

## Build and test

Use the Maven wrapper from the project root:

```bash
./mvnw -B verify
```

## Run the demo

```bash
./mvnw javafx:run -f pdfviewfx-demo/pom.xml
```

## How to contribute

- File issues using the corresponding GitHub issue form when one applies.
- Submit focused pull requests that address a single change.
- Describe user-visible changes clearly in your pull request.
- Update `CHANGELOG.md` when your change is user-facing or otherwise appropriate.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
