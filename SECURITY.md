# Security Policy

## Reporting a vulnerability

Please do not file public issues for exploitable vulnerabilities.

Use GitHub Security Advisories and the repository's **Report a vulnerability** flow when it is available. If that option is not available, report the issue privately by email to the maintainer address published in `pom.xml`:

- `dlemmermann@gmail.com`

When reporting, please include as much of the following as you can share safely:

- affected versions
- impact
- reproduction steps
- any proof of concept or log output that helps us understand the issue

Please avoid sharing exploit details publicly until the issue has been reviewed and addressed.
